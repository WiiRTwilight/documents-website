## 进入主页

点击[此链接](https://wardrobe.timeless-twilight.com)或者在地址栏输入`https://wardrobe.timeless-twilight.com/`，以进入页面。

![mainpage](https://img.bloret.net/img/1788240812325/a1cdffdd23ee03722acfe983d631f15c)

点击注册。

![reg-bs](https://img.bloret.net/img/1788241259987/a02992e55949d83758fcb1ae2dbef21a)

联系`love@tlipo.ca`(该网站的管理员之一)获取邀请码(不一定会给)。获取邀请码后填写上述信息，确认后来到主页。

（不要想着从图片获取邀请码信息，邀请码是一次性的）

![userpanel](https://img.bloret.net/img/1788241440574/1e9e220f7499874611b4bc4a6ece0cc2)

## 更衣

### 更换自己的皮肤

众所周知，我们日常生活中都是要买衣服挂进衣柜里，然后在想穿这套衣服的时候从衣柜里取用这套衣服。暮光的衣橱也一样，你可以将自己的皮肤上传，随后自己使用。

点击"我的衣柜"。

![my_wardrobe](https://img.bloret.net/img/1788242057018/044563f955c2a5ef29a12d954f48f144)

点击"上传皮肤"。

![upload_skin](https://img.bloret.net/img/1788242477674/1a9b501d9e5a751e92ef8df787183a0d)

填写信息后确认上传材质。

![after_upload_skin](https://img.bloret.net/img/1788242654229/23152150efd05e390110931edc947880)

点击"立即使用"。

![apply_skin](https://img.bloret.net/img/1788242965601/ec565e57a08cf288b32b7d81312c662e)

点击你的角色。然后就大功告成了！

### 更换皮肤库里已有的皮肤

这就好比你衣柜里面本来就有衣服，只是你某天想换了，就可以直接从衣柜里面拿衣服。

从主页进入皮肤库：

![skinlib](https://img.bloret.net/img/1788243112583/1a1565222854877ec86d27b955553f75)

点击你喜欢的皮肤：

![after_upload_skin](https://img.bloret.net/img/1788242654229/23152150efd05e390110931edc947880)

点击"立即使用"。

![apply_skin](https://img.bloret.net/img/1788242965601/ec565e57a08cf288b32b7d81312c662e)

点击你的角色，随后你就换上了别人的服装！

### 更换衣柜已有皮肤

从主页进入"我的衣柜"。

![closet](https://img.bloret.net/img/1788243352707/55107202c339c4af525578629897a080)

选择你已有的皮肤：

![choose_skin](https://img.bloret.net/img/1788243351266/e710e0e61a44e1c06e7b3bdaa210de57)

点击"使用"，选择角色后，你的形象就焕然一新辣！

## 更换头像

进入"我的衣柜"。

![my_wardrobe](https://img.bloret.net/img/1788242057018/044563f955c2a5ef29a12d954f48f144)

点击你所喜欢的皮肤的小齿轮图标：

![my_wardrobe_settings](https://img.bloret.net/img/1788255503347/66ad23b71368424feb1ac404859fc170)

点击"设为头像"，确认后你的皮肤头像就将出现在网站右上角。

## 绑定第三方账号

::: warning
注：该绑定流程与Blessing Skin主流实现和Little Skin实现不同，请勿在别的皮肤站照搬相同的绑定方式，不然当纱帽处理（
:::

有些猫猫可能认为，欸我绑定别的账号是不是方便点，所以这文档我也写上（

目前我们支持或者计划支持以下平台：

- [x] [Little Skin](https://littlesk.in) (支持还行，但是需要手动绑定账号)
- [ ] [Github](https://github.com) (报错"获取访问令牌失败")
- [ ] [Bloret通行证](https://passport.bloret.net) (实现不标准以至于除非未来专门适配否则无希望，~~以及我们一般不称其为OAuth~~)
- [ ] [MSCPO开放平台](https://open.mscpo.com) (目前还没问到接口文档)
- [x] [MCJPG社区通行证](https://mcjpg.org) (目前支持最好的，不过账号注册有门槛)

### 在"OAuth绑定管理"绑定账号

点击"OAuth绑定"。

![oauth_link](https://img.bloret.net/img/1788256804173/4d6f90ba423af5551d86a3834374c326)

选择平台点击绑定之后，按照流程登录账号并确认绑定即可。

### 在登陆页绑定账号

进入登录页(如果你已经登录了账号需要提前退出登录)。

![login-bs](https://img.bloret.net/img/1788258942255/29fdb56e13191f59428908bcee3e7059)

选择你希望使用的平台，按照流程登录账号并确认绑定即可。
