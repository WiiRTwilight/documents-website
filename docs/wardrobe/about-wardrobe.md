# 关于暮光的衣橱

~~顾名思义，这是暮光装衣服用的衣柜~~。这是一个基于[Blessing Skin](https://blessing.netlify.app/)，并含有一些特有特性的MC皮肤站。顾名思义，换MC皮肤这点类似于我们日常生活中换衣服，都是更改自己的形象，因此得名"暮光的衣橱"，又称"Twilight's Wardrobe"。

[该站点](https://wardrobe.timeless-twilight.com)虽然能够直接访问，但很抱歉该服务并不对人类公开，如有需要自己想办法从猫猫管理员那里要邀请码。

## 衣橱的特点

与大部分Blessing Skin站点相比，暮光的衣橱没有很明显的用户可感知的特点。也许特点是这个网站由猫猫狐狐维护运行？也许吧。

## 为什么要运营这个网站

我相信每一只狐狸每一只猫猫都会精心打扮自己，想办法变换成类人的身体，穿上人类的衣服的同时~~保留耳朵等让人感到可爱的外观特征~~，等来游戏里的一句"cute skin bro"。所以这个网站就这么上线啦！并且我其实同时出于折腾和好玩的心理运行维护这个网站，反正差不多就这样awa
